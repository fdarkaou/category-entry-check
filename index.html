Category entry check

Thinking about an app in a new App Store category? Before you build, compare a few categories on the same chart: what the apps at #10, #25 and #50 are estimated to make and download, how much of the estimated revenue the top 3 hold, how many apps released in the last two years made the chart, how many ratings the smallest top-25 app has, and how many charting apps run paid ads, get organic posts or rank top 10 for searches. The data is one stored leaderboard read per category from PeekPanda, an iOS competitor catalogue. Nothing leaves your browser; this page never calls the API.

Download and revenue figures are estimates, not measured results. A chart rank is where an app sat on that day, not why. "Not collected" is not zero. The page lines up the evidence; it does not score or pick a category.

Chart Rows per category Young = released within months

Where to get the JSON

Each answer needs a PeekPanda account and an API key with scope context:read, counts as one call toward your plan's daily API and MCP allowance, and only reads stored evidence. Over MCP the same read is the get_market tool with action leaderboard. See Get market leaderboard (the allowance per plan is on the plans page):

curl --get 'https://api.peekpanda.com/v1/market/leaderboard' \
  --header "Authorization: Bearer $PEEKPANDA_TOKEN" \
  --data-urlencode 'country=us' --data-urlencode 'categoryId=6013' \
  --data-urlencode 'chartType=grossing' > health.json

Category IDs are Apple's: 6013 Health & Fitness, 6007 Productivity, 6023 Food & Drink, 6015 Finance, 6017 Education, 6012 Lifestyle, 6008 Photo & Video and so on (node cli.js --list prints all 27). Put several answers in one JSON array to compare them.

Part of a set of small PeekPanda API samples. Source and command-line version: github.com/fdarkaou/category-entry-check (MIT). Example data is made up.
